Documentation

This documentation will guide you through the setup and usage of the InApp Inventory Dashboard template.

Prerequisites

Before you begin, ensure you have the following installed:

  • Node.js (v14 or higher)
  • npm or yarn package manager
  • Any other project-specific dependencies

Installation

  1. Clone the repository or download the template
  2. Navigate to the project directory
  3. Install dependencies:
    npm install

Run the app

To start the development server:

npm run dev

Next Steps

  1. Review the Angular entry point in src/main.ts
  2. Customize the page components according to your needs
  3. Build for production:
    npm run build

Project Structure

inapp/
├── src/
│   ├── app/            # Angular routes, layouts, and pages
│   └── assets/         # Static assets, images, and SCSS
├── angular.json        # Angular CLI configuration
├── package.json        # Project dependencies
├── tsconfig.json       # TypeScript configuration
└── README.md           # Documentation
